Sauvegarder / restaurer

Les chantiers validés sont enregistrés dans ce navigateur et les modifications en cours sont sauvegardées comme brouillon. Exporte régulièrement une sauvegarde JSON pour éviter de tout perdre si le navigateur ou ses données sont effacés. Aucun partage automatique entre appareils.
